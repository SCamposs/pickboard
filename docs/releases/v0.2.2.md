PickBoard 0.2.2 improves League Client synchronization reliability in ranked champion select.

## Fixes

- Accepts the temporary negative champion identifiers that the League Client can expose during ranked and Flex champion select.
- Keeps valid confirmed picks and bans when the same snapshot also contains hidden or unresolved champion placeholders.
- Continues synchronizing through periodic local snapshots if the League Client event stream is temporarily interrupted.
- Retries the event stream silently instead of showing a reconnecting state while local snapshot reads remain available.

## Downloads

- `PickBoard_0.2.2_x64-setup.exe` - standard Windows installer for the current user.
- `PickBoard_0.2.2_x64-portable.zip` - portable package containing only `PickBoard.exe`.

The release also includes `latest.json` and the installer signature used by the in-app updater.

The application is currently unsigned. Windows SmartScreen may display a warning on first launch.

## Known Limitations

- The League Client API is unsupported and may change without notice.
- Enemy roles are never inferred automatically.
- Some game modes may not provide reliable ally positions.
- Real-client compatibility should be rechecked after major League Client updates.
- Manual mode remains available whenever synchronization is disabled or unavailable.
