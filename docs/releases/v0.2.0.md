PickBoard 0.2.0 introduces optional, read-only synchronization with the local League Client while preserving every manual draft workflow.

## Highlights

- Detects the local League Client and reconnects automatically.
- Synchronizes confirmed ally picks, enemy picks, and bans in real time.
- Places ally picks only when the client provides a recognized role.
- Keeps enemy picks unassigned until the user records a likely position.
- Supports assigning, changing, and removing enemy role annotations without writing to the client.
- Includes unassigned enemies in copied draft prompts without treating list order as role order.
- Preserves the latest visible draft through disconnects and dodges.
- Starts a clean draft exactly once when a confirmed new champion-select session begins.
- Migrates existing local state to the new versioned schema.
- Fixes the application logo in the navigation rail.

## Safety and Privacy

- No Riot API key is required or embedded.
- Temporary LCU credentials remain inside the Rust backend and are never persisted or sent to the frontend.
- The integration performs no auto accept, auto pick, auto ban, rune changes, spell changes, chat actions, or other writes to the League Client.
- PickBoard has no telemetry, analytics, external backend, or remote draft storage.

PickBoard is an independent third-party application and is not endorsed by Riot Games.

## Known Limitations

- The League Client API is unsupported and may change without notice.
- Enemy roles are never inferred automatically.
- Some game modes may not provide reliable ally positions.
- Real-client compatibility should be rechecked after major League Client updates.
- Manual mode remains available whenever synchronization is disabled or unavailable.
