PickBoard 0.2.1 is a visual and packaging reliability patch for the 0.2 release.

## Fixes

- Packages the navigation brand mark as a local application asset so it loads correctly under the desktop security policy.
- Centers the ally and enemy team emblems and improves their visual size.
- Simplifies synchronization and privacy copy shown to users by removing developer-oriented implementation details.

## Downloads

- `PickBoard_0.2.1_x64-setup.exe` - standard Windows installer for the current user.
- `PickBoard_0.2.1_x64-portable.zip` - portable package containing only `PickBoard.exe`.

The application is currently unsigned. Windows SmartScreen may display a warning on first launch.

## SHA-256

Checksums will be added after the final artifacts are built and verified.

## Known Limitations

- The League Client API is unsupported and may change without notice.
- Enemy roles are never inferred automatically.
- Some game modes may not provide reliable ally positions.
- Real-client compatibility should be rechecked after major League Client updates.
- Manual mode remains available whenever synchronization is disabled or unavailable.
