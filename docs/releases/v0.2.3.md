PickBoard 0.2.3 fixes confirmed ban synchronization from the League Client.

## Fixes

- Reads confirmed bans from champion-select actions when the client's final ban lists remain empty.
- Combines action-based bans with the final ally and enemy ban lists without creating duplicates.
- Ignores hovered, pending, unresolved, and invalid ban actions.
- Preserves manual ban editing and the existing read-only League Client integration.

## Downloads

- `PickBoard_0.2.3_x64-setup.exe` - standard Windows installer for the current user.
- `PickBoard_0.2.3_x64-portable.zip` - portable package containing only `PickBoard.exe`.

The release also includes `latest.json` and the installer signature used by the in-app updater.

The application is currently unsigned. Windows SmartScreen may display a warning on first launch.

## SHA-256

Checksums are added after the release artifacts are generated.

## Known Limitations

- The League Client API is unsupported and may change without notice.
- Enemy roles are never inferred automatically.
- Some game modes may not provide reliable ally positions.
- Real-client compatibility should be rechecked after major League Client updates.
- Manual mode remains available whenever synchronization is disabled or unavailable.
